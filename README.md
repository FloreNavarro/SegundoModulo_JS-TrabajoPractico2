                                                   Trabajo Práctico N°2: Estructuras de Control
Este repositorio contiene la resolución de los ejercicios correspondientes al segundo trabajo práctico del módulo de JavaScript.
El objetivo principal es poner en práctica el uso de estructuras condicionales y bucles para resolver problemas de lógica de programación.

📋 Descripción:

El proyecto consiste en una serie de scripts que abordan diferentes desafíos lógicos, tales como:

- Determinación de números pares e impares.

- Validación de rangos numéricos.

- Uso de condicionales anidados (if, else if, else) y switch.

- Implementación de bucles para repetición de tareas (for, while, do-while).

- Manipulación básica de entradas de usuario.
  

 🛠️ Tecnologías Utilizadas:
 
- JavaScript (ES6+): Lenguaje principal para la lógica.

- Git & GitHub: Para el control de versiones y hosting del código.
